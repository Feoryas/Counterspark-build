# Counterspark (v0.2.3 test build)

Two circles of wizards. One live spark. Every reversal makes it faster.

**Play in your browser:** https://feoryas.github.io/Counterspark-build/
(desktop browser with a mouse; the first load is about 65 MB)

This is an early test build. Feedback is very welcome.

## How to play

- **Move:** WASD or arrow keys
- **Aim:** mouse
- **Reverse the spark:** left click, right click or Space, while the spark is inside your aim arc
- **Pause:** Esc (sound settings, main menu)
- **Fullscreen:** F11

Main menu > How to Play shows each mechanic in a short clip.
